# Ahmed Digital — Site vitrine

Un site vitrine responsive pour présenter les services de création de sites web d'Ahmed Digital. Il fonctionne sans framework, sans installation et sans dépendance externe.

## Avant la publication

1. Ouvrir `index.html`.
2. Chercher `const WHATSAPP_NUMBER = "212648534788";`.
3. Remplacer `212648534788` par votre numéro WhatsApp au format international, sans `+`, sans espaces et sans tirets. Pour un numéro marocain, utilisez `212` suivi du numéro sans le premier `0`.
4. Vérifier l'adresse e-mail dans le bouton e-mail et la modifier si nécessaire.
5. Ouvrir `index.html` dans un navigateur et tester les sections et boutons.

Les prix présentés sont des prix indicatifs modifiables. Vérifiez-les et adaptez-les à vos services avant de présenter le site à des clients.

## Publier gratuitement avec GitHub Pages

1. Sur GitHub, créez un dépôt public nommé `ahmed-digital-site`.
2. Cliquez sur **Add file → Upload files** et téléversez `index.html` et `README.md`.
3. Validez avec **Commit changes**.
4. Ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, sélectionnez **Deploy from a branch**, choisissez `main` et `/ (root)`, puis cliquez sur **Save**.
6. Attendez la fin du déploiement indiqué par GitHub Pages. Le lien du site apparaîtra dans la section Pages.

GitHub Pages convient à ce site statique. Il ne fournit pas à lui seul de base de données ni de système de comptes utilisateurs.
